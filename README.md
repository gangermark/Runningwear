# RunReady

Mobilanpassad svensk PWA med GPS, aktuellt väder från Open-Meteo och enkla klädråd för lugna pass, intervaller och långpass.

## GitHub Pages
Öppna Settings → Pages och välj Deploy from a branch, main, /(root), Save.

Appen finns därefter på https://gangermark.github.io/Runningwear/ . Öppna i Safari på iPhone och välj Dela → Lägg till på hemskärmen.

GPS kräver HTTPS och tillåten platsåtkomst. Väder kräver internet. Ingen backend eller API-nyckel behövs.

## Lokal utveckling
Kör python3 -m http.server 8000 och öppna http://localhost:8000 .
